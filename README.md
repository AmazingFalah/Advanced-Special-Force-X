# Advanced-Special-Force-X

Hey there, before we start explaining how to start this program, I want to tell you this is an upgrade version of previous version Special-Force-X
So, if you want to try the previous version first, you can access them in my Github.

Okay, to upgrade my previous work, I worked on making database and the program alot safer by implementing ACI (Availability, Confidentiality, Integrity)
So, I implemented backup system, 2 different menu depending on your role, and Audit Log.

**Alright, without futher ado, let met explain how to run this program:
1. Run the "ASFX" query in you phpmyadmin using XAMPP
2. After that, open "AdvacedGameManage.py" (You can start playing, because i have prepare for you a test account for testing the code)
3. After opening that program, you can start open "daily_backup.py"**

Okay for "AdvacedGameManage.py" you can start playing with it, However "daily_backup.py" is a bit tricky
For started, you have to prepare a folder in you "D:" directory named "project_backup", then you have activate the program every 1 AM
You can always improve this by integrating this into you machine to automate activate every 1 AM.
